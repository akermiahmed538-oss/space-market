# Space Market (Node.js + Express + SQLite)

Online store with real database: catalog, search, sorting, cart, checkout with stock control,
order tracking by email, and an admin panel (add/delete products, edit stock, update order status).

## Deploy on Render
Build Command: `npm install`  ·  Start Command: `npm start`
Environment variable: `ADMIN_PASSWORD` = your secret password

## Files
- server.js — API + database (market.db is created automatically with 12 sample products)
- public/index.html — storefront
